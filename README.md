# 🌐 Manjiri Arolkar — Personal Portfolio Website

> A responsive, modern personal portfolio built with pure HTML, CSS, and JavaScript — no frameworks.

🔗 **Live Site:** [manjiri-dev10.github.io/My-portfolio-website-](https://manjiri-dev10.github.io/My-portfolio-website-/)

---

## ✨ Features

- 🌙 Dark / Light mode toggle with localStorage persistence
- ⌨️ Typing animation with multiple roles
- 🎨 Smooth scroll reveal animations
- 📊 Animated skill progress bars
- 🗂️ Project filter by category (Python, Web, Games)
- 📬 Working contact form via EmailJS (no backend needed)
- 📱 Fully responsive — mobile, tablet, desktop
- ⚡ Zero frameworks — pure HTML, CSS, JavaScript

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structure & Semantics |
| CSS3 | Styling, Animations, Responsive Design |
| JavaScript (Vanilla) | Interactivity, DOM manipulation |
| EmailJS | Contact form email delivery |
| Font Awesome | Icons |
| Google Fonts | Typography (Clash Display, Cabinet Grotesk, JetBrains Mono) |
| GitHub Pages | Hosting |

## 📬 Contact Form Setup

This portfolio uses [EmailJS](https://emailjs.com) to handle form submissions without a backend.

To set it up yourself:
1. Create a free EmailJS account
2. Connect your Gmail service
3. Create an email template
4. Replace the `Service ID`, `Template ID`, and `Public Key` in `index.html`
